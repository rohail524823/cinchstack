Have your Realtor.com leads flow into Follow Up Boss seamlessly through API and Email Parsing.

 

API integration (Connections℠ Plus)

Note: This is a connection you'll want to enable in addition to the email parsing integration below. 

1. Create a Follow Up Boss API Key by going to Admin > API

2. Select Create API Key 

3. Name the API Key Realtor.com > Create API Key

4. Press Copy 

5. Log in to Realtor.com 

6. Use the drop-down menu in the top-right corner of the page and navigate to Settings > Lead Settings > Add Lead Delivery API

7. Choose Follow Up Boss as your API Source Application

8. Paste your Follow Up Boss API Key in the API Key section

9. Enter your Follow Up Boss login email address in the space for Application Login Name

 

Troubleshooting API integration error

If you see the error shown in the screenshot below, it likely means you have a Lead Flow for Realtor.com that is Archived. Unarchive the Realtor.com Lead Flow, then attempt the connection again. Click here for instructions on unarchiving Lead Flow Sources.

 
Email parsing integration (required)
Microsoft 365, GSuite, and Gmail users

Leads will flow into Follow Up Boss automatically via your Connected Email. Ensure Lead Processing is enabled for FUB to monitor your email inbox for new lead notifications and add them to Follow Up Boss automatically.

Alternative eetup

1. Copy your Follow Up Boss Lead Email Address by going to Admin > API

2. Log in to Realtor.com

3. Click your profile picture in the top right > Settings

4. Notification Settings > Send Email Notifications To

5. Paste your Follow Up Boss Lead Email Address > Save

6. Test the connection by clicking Send Test in the upper right-hand corner
